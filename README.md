# الصندوق — لعبة ألغاز ميكانيكية ثلاثية الأبعاد

لعبة ألغاز عربية بأسلوب «الغرفة»: تدوّر الأشياء بإصبعك، تسحب المزالج، تدير الأقراص، وتكشف ما لا يُرى. أربعة فصول متصلة بقصة واحدة.

**العب الآن:** افتح `index.html` (أو صفحة GitHub Pages الخاصة بالمستودع).

## الفصول
| # | الفصل | الألغاز |
|---|---|---|
| ١ | الصندوق | الصندوق والأقراص الرقمية، صندوق الموسيقى، درج الطاولة بالمغناطيس، تركيب عدسة ليلى |
| ٢ | الخزنة | العدسة والرموز، الأزرار المنزلقة، الفانوس والمرايا، الترس والآلة، قرص الخزنة، المقبض |
| ٣ | المرصد | الأسطرلاب، العدسة العينية والتلسكوب، لوحة الأذرع، القبة والكرة الأرضية |
| ٤ | القبو | صمامات الغلايات، شبكة الأنابيب، مفتاح الزمن، الساعة الكبيرة، الرافعة |

## التقنية
- صفحات HTML مستقلة، Three.js r128 من CDN، بلا أي بناء أو تثبيت.
- الخامات فوتوغرافية (`tex/`) مع خرائط Normal وخشونة مولّدة في المتصفح.
- معالجة لاحقة مكتوبة يدويًا: Bloom، انحراف لوني، حبيبات فيلم، Vignette، ووضع «العدسة».
- التقدّم والنجوم تُحفظ في `localStorage`.

## التشغيل محليًا
أي خادم ملفات ثابت يكفي (الخامات تحتاج http لا file://):
```
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000/`.
